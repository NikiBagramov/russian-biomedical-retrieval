# Third-party notices

The MIT license at repository root covers project-authored code. Benchmark texts, source libraries and pretrained weights retain their upstream terms; no model weights or raw datasets are republished. Pinned source/model provenance records identify releases and licenses where the model card states them. An unspecified card license is not replaced with an invented license.

RusBEIR source was inspected at a pinned commit but no top-level license was present. Its files are not redistributed here. Only source hashes are published; the project uses bm25s and the pytrec_eval API with independently written adapters.
